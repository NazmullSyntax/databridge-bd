# DataBridge BD

> **Your Data Requirements. Our Research. Reliable Insights.**

A professional **Business Data Collection & Research Marketplace** for Bangladesh.

Customers submit data requirements. Our research team collects, verifies, analyzes, and delivers.

## 🚧 Status

In active development. Not production-ready yet.

## 🏗️ Tech Stack

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript, Zod
- **Database:** PostgreSQL + Prisma
- **Auth:** JWT (httpOnly cookies), bcrypt, RBAC

## 📂 Structure

frontend/ → Next.js app
backend/ → Express API + Prisma
database/ → SQL backups, seeds
docs/ → Architecture, API docs
tests/ → E2E (Playwright)
